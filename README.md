# 💬 Client AI — Smart Reply Assistant

> WhatsApp, Telegram, Instagram pe client messages dekh ke AI se reply suggest karo!

---

## 🚀 GitHub Se APK Kaise Banayein (Step by Step)

### Step 1 — GitHub Account
- github.com pe account banao (free hai)

### Step 2 — New Repository Banao
- github.com/new pe jao
- Repository name: `client-ai-app`
- Public select karo
- Create repository click karo

### Step 3 — ZIP Upload Karo
1. GitHub repo page pe **"uploading an existing file"** click karo
2. ZIP extract karo apne computer pe
3. Saari files drag & drop karo GitHub pe
4. **"Commit changes"** click karo

### Step 4 — GitHub Actions Run Karo
1. Repo mein **"Actions"** tab pe jao
2. **"Build Flutter APK"** workflow dikhega
3. **"Run workflow"** click karo
4. ~5-8 minute wait karo

### Step 5 — APK Download Karo
1. Build complete hone ke baad **"Artifacts"** section mein
2. **"ClientAI-APK"** download karo
3. Phone pe install karo! ✅

---

## 📱 Phone Pe Setup

1. APK install karo
2. App open karo
3. **Settings** mein Groq API key daalo (groq.com se free milti hai)
4. **Accessibility** permission enable karo
5. **Overlay** ON karo
6. WhatsApp/Telegram open karo — magic dekho! ✨

---

## 🔑 Groq API Key (Free)

1. groq.com pe jao
2. Sign up karo (free)
3. API Keys section mein "Create API Key"
4. Copy karo aur app ke Settings mein paste karo

**Free limits:** 30 req/min, 6000 req/day — enough hai!
